Eigenvalues and Eigenvectors

From 3Blue1Brown, Essence of Linear Algebra, Chapter 14
Linear Algebra Lesson 11
Concept

Vectors That Do Not Get Knocked Off Their Span

Most vectors change direction when you apply a matrix transformation. An eigenvector is special: it lands back on its own span. The transformation only stretches or squishes it along its original line. It never rotates. The eigenvalue is the scalar that tells you by how much it was stretched or squished.

The core idea: a vector \(\mathbf{v}\) is an eigenvector of matrix \(A\) if \(A\mathbf{v} = \lambda\mathbf{v}\) for some scalar \(\lambda\). The scalar \(\lambda\) is the corresponding eigenvalue.

What the eigenvalue tells you

A positive eigenvalue greater than 1 means the eigenvector gets stretched in its direction. A value between 0 and 1 means it gets compressed. A negative eigenvalue means it gets flipped and possibly scaled. An eigenvalue of exactly 1 means the eigenvector is completely unchanged by the transformation.

Diagonal matrices are the easy case

For a diagonal matrix, the standard basis vectors are all eigenvectors and the eigenvalues are just the diagonal entries. This makes diagonal matrices very easy to work with. Raising a diagonal matrix to a large power is trivial: you just raise each diagonal entry to that power independently. For a general matrix, you would need to do repeated matrix multiplication.

When there are no real eigenvectors

A pure rotation matrix has no real eigenvectors. Every vector gets rotated off its span, so no real vector satisfies the eigenvector equation. The eigenvalues turn out to be complex numbers. This is not a failure of the concept. It just means the transformation has no preferred real direction that it leaves unchanged.

Formulas

Key Formulas

Eigenvector equation
\[ A\mathbf{v} = \lambda\mathbf{v} \]
Characteristic equation (find eigenvalues)
\[ \det(A - \lambda I) = 0 \]
Diagonal matrix power
\[ \begin{bmatrix} d_1 & 0 \\ 0 & d_2 \end{bmatrix}^n = \begin{bmatrix} d_1^n & 0 \\ 0 & d_2^n \end{bmatrix} \]
Eigenvector verification
\[ A\mathbf{v} - \lambda\mathbf{v} = \mathbf{0} \]
Code

Code Examples

All code below is taken verbatim from lesson-11-eigenvalues-eigenvectors.py.

Part 1: Finding eigenvalues and eigenvectors

np.linalg.eig returns the eigenvalues as a 1D array and the eigenvectors as columns of a 2D array. vec[:, 0] is the first eigenvector, vec[:, 1] is the second.

Python lesson-11-eigenvalues-eigenvectors.py 
import numpy as np

v = np.array([
    [1, 3],
    [5, 7]
])

# val contains the eigenvalues: the scalar by which each eigenvector gets scaled
# vec contains the eigenvectors as columns — vec[:, 0] is the first eigenvector
val, vec = np.linalg.eig(v)

print(f"Eigenvalues of v: {val}")
print(f"Eigenvectors of v: {vec}")
Output
Eigenvalues of v: [ 8.89897949 -0.89897949]
Eigenvectors of v: [[ 0.35506802 -0.84515425]
 [ 0.93498927  0.53452248]]

Part 2: Verifying the eigenvector property

For each eigenvector, multiplying the matrix by the eigenvector must equal multiplying the eigenvector by its eigenvalue. This confirms the vector only gets scaled, never rotated.

Python lesson-11-eigenvalues-eigenvectors.py 
# for each eigenvector verify that A @ eigenvector = eigenvalue * eigenvector
for i in range(len(val)):
    lhs = v @ vec[:, i]       # matrix times eigenvector
    rhs = val[i] * vec[:, i]  # eigenvalue * eigenvector
    print(f"A @ eigenvector {i}: {lhs}")
    print(f"lambda * eigenvector {i}: {rhs}")
    print(f"Are they equal? {np.allclose(lhs, rhs)}")
Output
A @ eigenvector 0: [3.16007272 8.32061399]
lambda * eigenvector 0: [3.16007272 8.32061399]
Are they equal? True

A @ eigenvector 1: [ 0.75969444 -0.48082613]
lambda * eigenvector 1: [ 0.75969444 -0.48082613]
Are they equal? True

Part 3: Diagonal matrices

A diagonal matrix has eigenvalues equal to its diagonal entries and the standard basis vectors as eigenvectors. Raising it to a large power is trivial: each diagonal entry is raised independently.

Python lesson-11-eigenvalues-eigenvectors.py 
diagonal = np.array([
    [3, 0],
    [0, 5]
])

val_d, vec_d = np.linalg.eig(diagonal)
print(f"Eigenvalues of diagonal matrix: {val_d}")

# computing the 100th power of a diagonal matrix is trivial
# you just raise each diagonal entry to the 100th power
power_100 = np.linalg.matrix_power(diagonal, 100)
print(f"diagonal^100 top-left entry: {power_100[0][0]}")
print(f"3^100 = {3**100}")
print(f"Are they equal? {power_100[0][0] == 3**100}")
Output
Eigenvalues of diagonal matrix: [3. 5.]
diagonal^100 top-left entry: 515377520732011331036461129765621272702107522001
3^100 = 515377520732011331036461129765621272702107522001
Are they equal? True

Part 4: Rotation has no real eigenvectors

A 90-degree rotation matrix rotates every vector off its span. No real vector satisfies the eigenvector equation. The eigenvalues come back as complex numbers.

Python lesson-11-eigenvalues-eigenvectors.py 
rotation = np.array([
    [0, -1],
    [1,  0]
])

val_r, vec_r = np.linalg.eig(rotation)
print(f"Eigenvalues of rotation matrix: {val_r}")
# eigenvalues will be complex numbers like 0+1j and 0-1j
# no real eigenvectors exist because every vector gets rotated off its span
print(f"Are eigenvalues complex? {np.iscomplex(val_r).any()}")
Output
Eigenvalues of rotation matrix: [0.+1.j 0.-1.j]
Are eigenvalues complex? True
AI Connection

How This Connects to AI

Why this matters for machine learning

Eigenvectors are the natural axes of a transformation. They are the directions in which a matrix acts most cleanly. In machine learning, finding these natural axes is often exactly what you want to do, and eigendecomposition is the tool that does it.

PCA (Principal Component Analysis) is built entirely on eigenvectors. Given a dataset, you compute the covariance matrix and then find its eigenvectors. Each eigenvector is a direction of variance in the data. The corresponding eigenvalue tells you how much variance lies along that direction. By keeping only the top few eigenvectors (the ones with the largest eigenvalues), you compress the data into its most important directions while discarding the rest. This is how researchers visualize 512-dimensional word embeddings in 2D: project onto the top two eigenvectors of the covariance matrix.

In transformer attention, the matrix \(QK^T\) has an eigenstructure that tells you which directions in embedding space the model pays most attention to. The eigenvectors with the largest eigenvalues represent the directions that get amplified most strongly during attention. This is a useful lens for interpretability research.

Diagonal matrices show up directly in transformers as scaling operations. Layer normalization scales each embedding dimension independently by a learned parameter, which is exactly multiplication by a diagonal matrix. The learned scale vector is essentially a set of eigenvalues for that scaling transformation.

The eigenvalue spectrum of a weight matrix also reveals a lot about training dynamics. If the largest eigenvalue is much bigger than 1, multiplying through that matrix repeatedly (as in a deep network) causes activations to explode. If all eigenvalues are smaller than 1, they vanish. Techniques like spectral normalization constrain the largest eigenvalue explicitly to stabilize training.
